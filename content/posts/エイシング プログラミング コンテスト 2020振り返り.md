## A - Number of Multiples
> L以上R以下の整数のうち、dの倍数であるようなものはいくつありますか？
> 
> 制約
> 
> 与えられる入力は全て整数
> 
> 1≤L≤R≤100
> 
> 1≤d≤100
> 
> [https://atcoder.jp/contests/aising2020/tasks/aising2020\_a](https://atcoder.jp/contests/aising2020/tasks/aising2020_a)

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
public class Hello
{
    public static void Main()
    {
		//left,right,dの値を保持する
        var LRd = Console.ReadLine().Split().Select(e => int.Parse(e)).ToArray();
        var L = LRd[0];
        var R = LRd[1];
        var d = LRd[2];
        var ans = 0;
		//問題文通りL以上R以下である数字のうちdの倍数を数え上げる
        for (var num = L; num <= R; num++)
        {
            if (num % d == 0)
            {
                ans++;
            }
        }
        Console.WriteLine(ans);
    }
}
```

## B - An Odd Problem
> 1,2,3,…,Nの番号がついたN個のマスがあります。各マスには整数が書かれており、マスiにはaiが書かれています。以下の2つの条件の両方を満たすマスはいくつありますか？
> 
> ・マスの番号は奇数
> 
> ・マスに書かれた整数は奇数
> 
> 制約
> 
> 与えられる入力は全て整数
> 
> 1≤N,ai≤100
> 
> [https://atcoder.jp/contests/aising2020/tasks/aising2020\_b](https://atcoder.jp/contests/aising2020/tasks/aising2020_b)

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
public class Hello
{
    public static void Main()
    {
		//Nの値を保持する
        var N = int.Parse(Console.ReadLine());
        //a1a2a3…aNの値を配列で保持する
		var aArray = Console.ReadLine().Split().Select(e => int.Parse(e)).ToArray();
        var ans = 0;
		//下記の条件を満たす要素の数をカウントアップして回答とする
		//配列のindex+1が奇数であり、かつ配列内の値が奇数である
        for (var cnt = 0; cnt < N; cnt++)
        {
			if ((cnt + 1) % 2 == 1 && aArray[cnt] % 2 == 1)
            {
				ans++;
            }
        }
        Console.WriteLine(ans);
     }
}
```

## C - XYZ Triplets
問題を一目見て数学の問題と判断し、しり込みしましたが、単純な全検索の問題に置き換えて解くことができる問題でした。解説を読みながら復習を実施しました。

> f(n)を以下の2つの条件の両方を満たすような3つの整数の組(x,y,z)の個数とします。
> 
> ・1≤x,y,z
> 
> ・x^2+y^2+z^2+xy+yz+zx=n
> 
> 整数 N が与えられるので、f(1),f(2),f(3),…,f(N)をそれぞれ求めてください。
> 
> 制約
> 
> 与えられる入力は全て
> 
> 整数1≤N≤10^4
> 
> [https://atcoder.jp/contests/aising2020/tasks/aising2020\_c](https://atcoder.jp/contests/aising2020/tasks/aising2020_c)

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Hello
{
    static void Main(string[] args)
    {
        //Nの値を保持する
        var N = int.Parse(Console.ReadLine());
        //回答用の配列をN分用意しておく
        var ans = new int[N + 1];
        //x,y,zをそれぞれ0～120の範囲でループする
        //Nは1≦N≦10^4なのでx,y,zいずれかが100を超えた値の場合下記の条件を満たさない
        //x^2+y^2+z^2+xy+yz+zx=n
        for (var x = 1; x < 120; x++)
        {
            for (var y = 1; y < 120; y++)
            {
                for (var z = 1; z < 120; z++)
                {
                    var temp = x * x + y * y + z * z + x * y + y * z + z * x;
                    //Nの値を超えない範囲で回答用配列をカウントアップ
                    if (temp <= N)
                    {
                        ans[temp]++;
                    }
                }
            }
        }
        //最後にN行分回答を出力して終了
        for (var num = 1; num < N + 1; num++)
        {
            Console.WriteLine(ans[num]);
        }
    }
}
```
